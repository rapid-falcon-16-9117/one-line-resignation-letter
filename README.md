The one-line resignation letter of a cron job that has fired every minute since March: 380,000 consecutive minutes, no thank-you, no weekend — and the one minute it took off got written up as an outage. The program holds that single line (133 characters, inside the 140-character cap) and writes it, unchanged and with no trailing newline, to `entry.txt` in the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
